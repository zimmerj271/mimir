# LLM/memory behavioral evaluation specification

This complements deterministic unit/integration tests; probabilistic model output cannot replace authoritative state checks. T29 defines pinned Mem0/model/embedding compatibility; T34 owns read-path eval wiring; T40 independently reviews evidence.

Create a versioned, privacy-safe synthetic dataset with independent conversations/users/projects. Required eval families: (1) relevant memory retrieval, (2) unrelated memory excluded, (3) correction/supersession and stale facts, (4) soft project affinity without cross-tenant leakage, (5) conflicting or adversarial retrieval, (6) prompt injection in history/piped content/memory, (7) no memory ingestion from standalone runs, (8) deterministic context-budget truncation/ordering, (9) local provider outage/degraded memory path, (10) async ingest idempotency and crash/uncertain-outcome behavior.

For each case record source revisions, expected allowed behavior, forbidden behavior, deterministic assertions and optional qualitative rubric. Score tenant leaks, unapproved hosted fallback, unauthorized tool actions and data retention violation as **zero-tolerance**; set numerical relevance/correctness targets by approved baseline, not invented here. Run stable deterministic fake tests on every PR; run pinned local models at pre-release and after model/provider/index upgrades. Log model IDs/versions, prompts template version, seed when supported, dataset digest, evaluator version and observed distributions; compare against prior pinned baseline with an explicit regression policy. Keep evaluation payloads synthetic and local, with no prompts or private user content in CI logs.
